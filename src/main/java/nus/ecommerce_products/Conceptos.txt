Configuración correcta: spring.datasource.url=jdbc:mysql://localhost:3306/ecommerce_db con root sin contraseña.

2. Modellare l’entità Prodotto
Definisci una classe JPA Prodotto che rappresenti un prodotto di e-commerce, con i campi principali (id, nome, descrizione, prezzo, quantità disponibile, date di creazione e aggiornamento).
La tabella dovrà chiamarsi prodotti.

@Entity y @Table(name = "prodotti") convierten una clase Java en una tabla MySQL, donde cada campo es una columna.
@Id + @GeneratedValue(strategy = GenerationType.IDENTITY) hace que el ID sea auto-incrementable en la base de datos.
@PreUpdate actualiza automáticamente dataAggiornamento cada vez que se modifica un producto, mientras updatable = false
 protege dataCreazione.

 3. Implementare le regole di mapping
 Assicurati che ogni campo sia mappato correttamente sul database con vincoli e tipi coerenti
 (es. BigDecimal per il prezzo, @Lob per la descrizione).
 Verifica la corretta generazione della tabella in phpMyAdmin.

 spring.jpa.hibernate.ddl-auto=update crea y actualiza automáticamente las tablas en MySQL
 basándose en las entidades JPA, sin necesidad de escribir SQL manual.
 Anotaciones clave: @Column(nullable=false, length=100), @Lob para TEXT, BigDecimal con precision=10, scale=2
 para precios, y unique=true para evitar duplicados.
 Solo la base de datos debe crearse manualmente (ej: ecommerce_db); Spring Boot crea las tablas (prodotti)
 automáticamente al arrancar la aplicación.

19. Gestire prodotti esauriti

@Query define una consulta JPQL (no SQL nativo) que selecciona productos donde quantitaDisponibile es igual al parámetro :zero.
@Param("zero") vincula el valor del parámetro del método (int zero) con el parámetro nombrado :zero en la consulta JPQL.
Es segura contra SQL Injection porque usa parámetros nombrados en lugar de concatenar strings, y Hibernate escapa automáticamente los valores.
